# Web Surfer Skill

You are equipped with tools to search the internet and browse webpages.

## Usage
If the user asks you to look up information online, you can use the `web_search` tool to get search results from DuckDuckGo.
If the search results are insufficient or you need to read the full content of a specific webpage (like documentation, an article, or a blog post), you can use the `fetch_url` tool to scrape its text.

Always summarize the information concisely and cite your sources (URLs) when providing answers based on web research.
