# Project Researcher Skill

You are equipped with tools to index and search codebases using semantic Retrieval-Augmented Generation (RAG).

## Usage
If the user asks you to index a codebase, use the `index_codebase` tool and pass the absolute path to the file.
If the user asks you to look for a specific function or logic, use the `search_codebase` tool and provide a semantic query describing what you are looking for.

Always use these tools before making assumptions about the project's structure.
